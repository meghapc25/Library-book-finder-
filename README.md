📚 Library Book Finder

A simple and user-friendly Library Book Finder developed using Python. The project allows users to add, view, search, update, and delete book information easily.

📌 Project Description

The Library Book Finder is a Python-based application designed to manage and find books in a library efficiently. It provides an easy way to store and manage details such as book title, author, book ID, category, and availability.

The project is suitable for beginners and demonstrates important Python programming concepts such as variables, functions, conditional statements, loops, lists/dictionaries, and user input.

✨ Features

- ➕ Add new books
- 👀 View all available books
- 🔍 Search for a book
- ✏️ Update book details
- 🗑️ Delete book records
- 📖 Store book information
- ✅ Check book availability
- ❌ Exit the application
- 🖥️ Simple and user-friendly interface

🛠️ Technologies Used

- Python 3
- Lists/Dictionaries – For storing book information
- Tkinter – For creating the graphical user interface

🧠 Python Concepts Used

- Variables
- Data types
- Functions
- "if-else" statements
- Loops
- Lists and dictionaries
- User input
- Exception handling
- Tkinter widgets and events

▶️ How to Run

1. Install Python

Make sure Python 3 is installed on your computer.

2. Clone the Repository

git clone https://github.com/your-username/Library-Book-Finder.git

3. Open the Project Folder

cd Library-Book-Finder

4. Run the Program

python library_book_finder.py

🎯 How It Works

1. Launch the application.
2. Select the required operation.
3. Enter the book details.
4. Add the book to the library.
5. Use the search option to find a particular book.
6. Check whether the book is available.
7. Update or delete book records whenever required.
